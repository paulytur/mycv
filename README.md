# Backend Developer Portfolio

A professional portfolio website showcasing backend development expertise with Microsoft technologies.

## Features

- **Modern Design**: Clean, professional layout with smooth animations
- **Responsive**: Mobile-first design that works on all devices
- **Interactive**: Smooth scrolling, dynamic navigation, and contact form
- **Performance Optimized**: Fast loading with optimized animations
- **SEO Friendly**: Proper meta tags and semantic HTML structure

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with Grid, Flexbox, and animations
- **JavaScript**: Interactive functionality and smooth user experience
- **Font Awesome**: Professional icons
- **Google Fonts**: Inter font family for modern typography

## Sections

1. **Hero Section**: Professional introduction with animated code snippet
2. **About**: Personal background and key statistics
3. **Skills**: Technical expertise with progress indicators
4. **Experience**: Professional timeline with detailed descriptions
5. **Projects**: Featured work with technology tags
6. **Contact**: Contact form and social media links

## Customization

To customize this portfolio for your own use:

1. **Personal Information**: Update the content in `index.html`:
   - Replace "Your Name" with your actual name
   - Update contact information in the contact section
   - Modify the hero description and about section

2. **Experience & Projects**: 
   - Update the timeline in the experience section
   - Replace project descriptions and links
   - Adjust skill levels in the skills section

3. **Styling**: 
   - Modify colors in `styles.css` by updating the CSS custom properties
   - Adjust the gradient colors throughout the file
   - Change fonts by updating the Google Fonts import

4. **Content**:
   - Add your actual project links
   - Update social media URLs
   - Replace placeholder statistics with real numbers

## Performance Features

- Throttled scroll events for smooth performance
- Lazy loading animations
- Optimized CSS animations
- Minimal external dependencies

## Contact Form

The contact form includes:
- Client-side validation
- Visual feedback for user actions
- Responsive design
- Accessibility features

Note: The form currently shows a success message but doesn't actually send emails. To make it functional, you'll need to:
- Add a backend service (PHP, Node.js, etc.)
- Integrate with email services like EmailJS, Formspree, or Netlify Forms
- Or use serverless functions (Azure Functions, AWS Lambda)
